# Web3Rough

Web3Rough enables decentralized, blockchain-based data storage and automated smart contract execution within a scalable network framework.

With Web3Rough, you get a lightweight tool that stays out of your way.

**What you get**

- Web3Rough enables decentralized, blockchain-based data
- storage and automated smart contract
- execution within a scalable network

- javascript
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Rough.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
